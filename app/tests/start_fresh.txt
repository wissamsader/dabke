# START FRESH (0.18). SAVE held while the FM-1 is switched on brings up the START FRESH page instead of the home page.
# SAVE there: every setting, every track's sound, the loops, the steps, the locks and the MY SOUNDs as on DABKE's first
# start, made by the same code an empty flash runs, and so after every start from then on. HOME, or any other button,
# leaves the page and changes nothing; the keys, the knobs and the MIDImix do nothing there. DABKE's own objects only:
# the flash outside them (another firmware's data, the panel's calibration) stays byte for byte. Without SAVE held a
# start is as 0.17's. From the repository's root:
#   app/build/host/dabke_host app/tests/start_fresh.txt OUTDIR

# the engine's tracks, knobs and locks, the same as when it was kept; fresh: the START FRESH page up)

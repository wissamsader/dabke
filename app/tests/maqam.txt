# The maqamat (0.18), written in app/dabke_maqamat.h as their notes in letters ("D Eh F G A Bb C", 'h' a half flat) and
# turned into keys as DABKE starts: every line read whole, and the first fifteen exactly as 0.17 had them as masks, in
# the same places (the saved settings keep a maqam by its place). Then the maqam page: a key of the maqam white, one
# outside it grey, a retuned one amber, on the white keys and the black keys alike. From the repository's root:
#   app/build/host/dabke_host app/tests/maqam.txt OUTDIR
# (maqam_bad: the lines with a note that cannot be read; maqam_changed: of the first fifteen, those not as 0.17's;
# maqam_try NOTES: a line read as the list's are, its notes not read (try_bad), its tonic's key (try_root, 0 C .. 11 B),
# its scale and its quarter-tone flats, a bit each from the tonic (try_scale, try_flat); mq_colN: key N's colour on the
# maqam page, 0 grey, 1 white, 2 amber)
wait 900
expect maqam_bad 0
expect maqam_changed 0
expect maqam_count >14
# lines read as the list's are: Rast (0xAB5, 0x810), Iraq on B half flat (0x56B, 0x021), Hijaz Kar as C Db or C C#
maqam_try C D Eh F G A Bh
expect try_bad 0
expect try_root 0
expect try_scale 2741
expect try_flat 2064
maqam_try Bh C D Eh F G A
expect try_bad 0
expect try_root 11
expect try_scale 1387
expect try_flat 33
maqam_try C Db E F G Ab B
expect try_scale 2483
maqam_try C C# E F G G# B
expect try_bad 0
expect try_scale 2483
# what the check catches: a letter that is not a note, a sign that is not one, a small letter, two notes on one key,
# a line with no notes
maqam_try C D Xh F
expect try_bad 1
maqam_try C D Ez F
expect try_bad 1
maqam_try C d E F
expect try_bad 1
maqam_try C D D# Eb
expect try_bad 1
maqam_try
expect try_bad 1
